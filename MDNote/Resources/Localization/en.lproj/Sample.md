# Welcome to MD Note

**MD Note** renders Markdown as one continuous page that you can write on with Apple Pencil. Scroll with your finger, draw with your pencil, and pinch to zoom.

## Your notes, in context

Edit Markdown in your favorite editor, then read and annotate it here. When the document changes, handwriting follows its original text blocks.

> Handwriting is anchored to **document blocks**, rather than just screen coordinates. If a block is removed, its handwriting goes to the ink tray for you to restore.

### Getting started

1. Import a Markdown file from the library's Add menu.
2. To include local images, import the folder containing the note and its images.
3. Open the note and start writing with Apple Pencil.
4. Use the More menu to choose paper and text size, or export your work.

- Pencil: draw
- Finger: scroll
- Pinch: zoom the text and handwriting together

## Try a long page

Write beside this paragraph, then add text above it in an external editor. Your handwriting should move with the paragraph.

Each block has a content identity, and repeated blocks are distinguished by their order.

You can zoom in for detailed handwriting. The text and ink use the same scale.

The bottom of each document has extra space so you can keep writing below the last line.
