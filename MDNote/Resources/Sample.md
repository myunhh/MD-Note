# MD Note 샘플 문서

이 문서는 **MD Note**의 렌더링과 필기 레이어를 시험하기 위한 예제입니다. Apple Pencil로 이 글 위에 자유롭게 필기해 보세요. 손가락으로는 스크롤, 펜으로는 그리기입니다.

## 왜 만들었나

기존 필기앱은 *페이지 단위*라 마크다운 문서처럼 길이가 유동적인 글과 잘 맞지 않습니다. MD Note는 Notion처럼 **하나의 긴 페이지**로 열어 스크롤하며 필기합니다.

> 필기는 화면 좌표가 아니라 **문서 블록**에 묶입니다. 그래서 글이 바뀌어 밀려도 필기가 원래 내용 옆을 따라갑니다.

### 핵심 아이디어 세 가지

1. 스크롤러는 단 하나 — 웹 렌더와 필기 캔버스가 한 덩어리로 움직임
2. 필기를 블록에 앵커 — 글이 밀려도 따라옴
3. 외부 편집 감지 — VSCode에서 고쳐도 필기를 재정렬

- 펜: 그리기
- 손가락: 스크롤
- 핀치: 확대/축소(웹과 필기가 같은 배율)

## 코드도 예쁘게

```swift
func reanchor(ink: [AnchoredInk], old: [Block], new: [Block]) -> Result {
    let pairs = BlockMatcher.match(old: old, new: new)
    // 살아남은 블록은 따라오고, 사라진 블록의 필기는 보관함으로
    return classify(ink, survivors: pairs)
}
```

인라인 코드 `PKCanvasView`도 이렇게 표시됩니다.

## 표 렌더링

| 기능        | 상태      | 비고                     |
|-------------|-----------|--------------------------|
| MD 렌더     | 완료      | markdown-it              |
| 블록 앵커링 | 완료      | LCS 매칭, 테스트 통과    |
| 필기 캔버스 | 진행 중   | PencilKit                |
| 변경 감지   | 진행 중   | 포그라운드 폴링          |

## 길게 스크롤해 보기

아래는 스크롤과 필기 정렬을 시험하기 위한 채움 문단입니다.

문단 하나. 이 줄들 위에 필기를 해 두고, 위쪽에 내용을 추가한 뒤 다시 열면 필기가 따라 내려오는지 확인할 수 있습니다.

문단 둘. 블록마다 고유한 내용 해시가 있어, 같은 내용이 여러 번 나와도 순번으로 구분합니다.

문단 셋. 코드 블록이나 표처럼 높이가 크게 변하는 블록 위의 필기는 가장 취약하므로 따로 보강할 예정입니다.

문단 넷. 여기까지 스크롤하면서 필기가 글자 위에 정확히 얹히는지, 확대해도 어긋나지 않는지 보세요.

문단 다섯. 마지막 문단입니다. 문서 끝에도 여백을 충분히 두어 마지막 줄 아래에도 필기할 수 있습니다.
